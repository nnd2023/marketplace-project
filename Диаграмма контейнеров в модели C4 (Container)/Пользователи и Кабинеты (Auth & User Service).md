# Контейнер: Пользователи и Кабинеты (Auth & User API + Users DB)
## Зачем нужен: 
Управление пользователями, ролями, профилями продавцов и аутентификацией/авторизацией. Обеспечивает регистрацию, вход, восстановление пароля, управление данными пользователя и ролевую модель (покупатель, продавец, персонал, администратор).

## Входные данные:

- Регистрационные данные (email, пароль, телефон, имя)
- Учётные данные для входа (email/телефон + пароль)
- JWT-токен для обновления профиля
- Запросы на смену роли, привязку магазина
- Административные запросы (блокировка, удаление)

## Выходные данные:

- JWT-токен (access + refresh) при успешном входе
- Информация о пользователе (профиль, роли, магазин)
- Подтверждение создания/обновления профиля
- Ошибки валидации, конфликты (email уже используется)

## Интеграции:

- Чтение/запись в UsersDB (PostgreSQL) — схемы UserAccount, UserRole, UserRoles, SellerStore

- Проверка токенов для API Gateway (возможно, внутренний endpoint)

- Интеграция с внешним сервисом отправки email для подтверждения (через NotificationSvc)

- (опционально) Публикация события UserRegistered в Message Broker для приветственных уведомлений

## Нефункциональные требования:

- Время ответа на логин < 500 мс
- Безопасное хеширование паролей (bcrypt/argon2)
- Поддержка OAuth2/SSO (социальные сети)
- Защита от брутфорса (rate-limiting на уровне Gateway)
- Хранение refresh-токенов для долгой сессии
- Масштабирование чтения (реплики БД для профилей)
