# Контейнер: Товарный каталог (Catalog API + Catalog DB + Search Engine)
## Зачем нужен: 
Управление товарами, категориями, ценами, остатками и медиа-метаданными. Предоставляет API для поиска, фильтрации и получения деталей товаров. Обеспечивает синхронизацию индекса Elasticsearch для быстрого поиска.

## Входные данные:
 
- CRUD-запросы на товары (название, описание, цена, категория, остатки, изображения)
- Запросы на управление категориями
- Поисковые запросы (текст, фильтры, сортировка, пагинация)
- Обновления цен и остатков (от продавцов или систем складского учёта)
- Загрузка изображений (метаданные; файлы уходят в CDN)

## Выходные данные:

- Список товаров с пагинацией и фильтрацией
- Детальная карточка товара (включая presigned URL для изображений)
- Результаты полнотекстового поиска с фасетами
- Подтверждение обновления/удаления товара
- Индексные данные, отправленные в Search Engine (через CDC/Queue)

## Интеграции:

- Чтение/запись в CatalogDB (PostgreSQL) — схемы ProductCategory, Product, MediaAsset
- Синхронизация с Search Engine (Elasticsearch) для индексации
- Интеграция с CDNStorage для получения presigned URL-адресов при загрузке/выдаче изображений
- (возможно) Потребление событий из Message Broker для обновления остатков (например, после оформления заказа)
- API Gateway forward запросов

## Нефункциональные требования:

- Время ответа на получение товара < 100 мс (из кеша)
- Поиск < 200 мс (P95)
- Индексация в Elasticsearch с задержкой < 1 секунда (near real-time)
- Поддержка десятков миллионов товаров

Кеширование популярных запросов (Redis)

Автоматическое обновление индекса при изменении данных (CDC)
