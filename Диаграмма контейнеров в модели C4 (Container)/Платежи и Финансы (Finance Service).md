# Контейнер: Платежи и Финансы (Finance API + Finance DB + Payout Scheduler)
## Зачем нужен: 
Обработка платежей (холдирование, списание, возвраты), расчёт комиссий маркетплейса, управление выплатами продавцам и генерация реестров для массовых выплат через банк/ФНС.

## Входные данные:

- Данные для оплаты (сумма, способ, реквизиты карты через PaymentGateway)
- Запрос на создание выплаты продавцу (сумма, период)
- Статусы транзакций от PaymentGateway
- Команда на запуск пакетных выплат от PayoutScheduler

## Выходные данные:

- Статус платежа (success/failed)
- Идентификатор транзакции (payment_id)
- Реестр выплат (список продавцов, суммы, реквизиты) для передачи в BankSystem
- События: PaymentCompleted, PayoutScheduled (публикуются в Message Broker) 
- Отчёты по комиссиям и выплатам

## Интеграции:

- Внешний PaymentGateway (эквайринг, валидация карт) — инициирование холда/списания, получение статуса
- Внешний BankSystem (или ФНС) — отправка реестров выплат, получение подтверждений
- Чтение/запись в FinanceDB (PostgreSQL) — схемы Payment, Payout, PayoutItem
- Публикация событий в Message Broker (PaymentCompleted, PayoutScheduled)
- PayoutScheduler (Quartz/Cron) триггерит массовые выплаты через FinanceAPI и читает FinanceDB для формирования реестров
- API Gateway forward запросов (например, для оплаты)

## Нефункциональные требования:

- Время обработки платежа < 5 сек (включая внешние вызовы)
- Атомарность и согласованность (ACID) в FinanceDB
- Журналирование всех финансовых операций для аудита
- Защита от мошенничества (fraud detection)
- Поддержка различных валют и платёжных методов
- Пакетные выплаты должны завершаться в течение заданного окна (например, ночью)
