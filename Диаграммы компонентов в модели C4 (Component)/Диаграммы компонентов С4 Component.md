# Диаграммы компонентов (C4 Component)

Диаграмма C4 Component это схема третьего уровня модели C4, которая показывает крупные логические блоки кода внутри одного контейнера. Диаграмма компонентов служит мостом между архитектурой системы и структурой исходного кода, детализируя, из каких крупных «кирпичиков» состоит контейнер и как они обмениваются данными.

На диаграмме контейнеров (уровень C2) была определена общая структура системы. Для детальной проработки на уровне компонентов выбраны три контейнера, обладающие наиболее сложной внутренней логикой и критичные для ключевых бизнес-сценариев маркетплейса.

## Выделены следующие контейнеры для описания через диаграммы компонетов:
| **Номер** | **Наименование контейнера** | **Описание** | 
| ---- | ---- | ---- | 
| 1. | Пользователи и Кабинеты (Auth & User Service)| Управление пользователями, ролями, профилями продавцов и аутентификацией/авторизацией.|
| 2. | Заказ и Логистика (Order & Logistics Service)| Управление корзиной, оформлением заказов, статусной моделью (DRAFT → PAID → SHIPPED → DELIVERED), а также синхронизация с внешней службой доставки для отслеживания трекинг-номеров и статусов отправлений.|
| 3. | Платежи и Финансы (Finance Service)| Обработка платежей (холдирование, списание, возвраты), расчёт комиссий маркетплейса, управление выплатами продавцам и генерация реестров для массовых выплат через банк/ФНС.|

Данные контейнеры выделены для детализации ввиду их сложной внутренней структуры и высокой критичности для бизнес-процессов маркетплейса.
